## 一、产品概述

**大爷六爻**是一款面向六爻卜筮爱好者的专业级排盘与解读工具，以「古典智慧、现代技术」为核心理念，将传统六爻预测学说的完整体系以数字化方式呈现。应用涵盖起卦、排盘、神煞、卦爻辞、万年历、AI 智能解读等全流程功能，是六爻学习者与从业者的得力助手。

六爻预测是中华传统术数的重要分支，以《周易》六十四卦为基础，通过纳甲、世应、六亲、六兽、神煞等多维度体系推断事物发展态势。大爷六爻 App 完整继承了这一学术体系，并在交互体验层面做了大量创新——从物理传感器驱动的随机起卦，到精美的毛玻璃质感卦盘，再到覆盖 245 种内置神煞的自定义神煞引擎，处处体现了对传统智慧的尊重与对现代技术的追求。

## 三、起卦方式 —— 五种古法，一触可得

App 支持五种起卦方式，通过顶部标签栏自由切换，满足不同场景的预测需求：

### 3.1 时间起卦

基于用户设定的农历年、月、日、时辰参数，以经典算法推算上下卦与动爻。配合弹性四柱面板，用户可精确调整八组干支选择器（年干、年支、月干、月支、日干、日支、时干、时支），为后续所有起卦方式设定统一的时间基准。

### 3.2 随机起卦（一键起卦）

App 自动模拟六次摇卦过程，每次生成三枚铜钱的正反面组合，逐爻以动画呈现老阴、少阳、少阴、老阳结果，如同真实掷币。随机数的生成融合了**设备物理熵源**——详情见下文第四章。

### 3.3 摇卦（金钱卦模拟）

模拟传统金钱卦的三枚铜钱掷卦法。用户每次点击"摇卦"按钮，App 以**开源通宝铜钱高清图片**替代纯文字显示，铜钱带有滚动动画，6 次完整摇卦后解锁排盘按钮。进度条以阳爻/阴爻/动爻标识实时显示每爻结果。

### 3.4 数字起卦

经典三数起卦法：用户输入三个数字，App 按 «梅花易数» 规则取上下卦与动爻。

### 3.5 自选卦

面向有经验的用户，支持通过两组选择器手动指定本卦和变卦的上下卦组合，适合已知卦象直接排盘的场景。

## 四、物理熵与陀螺仪 —— 真随机性的技术保障

### 4.1 环形缓冲区物理熵采集

大爷六爻的随机起卦引擎在技术层面做了大量投入，确保起卦结果的**不可预测性**：

- **持续加速度采样**：设备陀螺仪/加速度计以高频采样 x、y、z 三轴加速度数据，维护一个环形缓冲区持续储存最近 20 帧数据
- **差值熵计算**：每次起卦时，读取缓冲区中三轴各自的最大值与最小值，以 max − min 的差值作为物理熵值
- **CSPRNG 密码学安全混合**：通过 `crypto.getRandomValues()` 生成密码学安全随机数，再将物理熵通过折叠算法混合，确保不受单一熵源偏差影响
- **时间戳熵回退**：当设备传感器不可用时，自动回退到微秒级时间戳熵源，确保在任何环境下都能获得高质量随机性

### 4.2 陀螺仪摇卦

除手动点击外，App 还支持**摇动手机自动触发摇卦**：

- 启动 `DeviceMotionEvent` 监听，实时检测设备加速度幅度
- 当摇动强度超过设定阈值时，自动触发一次摇卦并进入冷却期防止误触发
- UI 界面提供加速度强度实时仪表条，用户可直观感受摇动力度

## 六、神煞体系 —— 245 种内置 + 无限自定义

### 6.1 完整的内置神煞库

神煞是六爻预测中不可或缺的辅助信息。大爷六爻内置了 **245 种神煞**，分为两大类：

| 类别 | 数量 | 索引方式 | 说明 |
|------|------|---------|------|
| 天干神煞 | 33 种 | 以日干为索引（10 位数组） | 如天乙贵人、文昌、禄神等 |
| 地支神煞 | 212 种 | 以月支/日支为索引（12 位数组） | 如桃花、驿马、华盖、将星等 |

### 6.2 十二大功能分类

所有神煞按实际应用场景划分为 **12 个功能分类**，用户可按类别筛选查看：

> 常用 · 十二元神 · 婚恋 · 功名 · 财运 · 官司 · 出行 · 生死疾病 · 鬼神 · 化解 · 特殊 · 家宅失窃

### 6.3 爻位神煞面板

在排盘详情页，点击任意爻位可展开该爻的专属神煞面板，以地支为组展示主卦、伏神、大伏、变卦四种来源下匹配的吉凶神煞。面板中还自动计算卦身位置与四柱旺相关系（太岁、月建、日建、时建、旺、生、休囚）。

### 6.4 自定义神煞引擎

用户可以**完全自定义神煞**：

- **基本类型**：支持天干类（10 值）、地支类（12 值）、五行类、纳音类四种参照类型
- **规则覆盖**：不仅可新增神煞，还可覆盖内置神煞的起法规则与柱位设置
- **可见性控制**：用户可隐藏任意神煞
- **规则校验**：保存时自动校验值的数量是否匹配，不匹配时发出警告但不阻止保存

## 七、排盘详情 —— 多维度交互探索

排盘详情页是 App 的核心交互界面，在完整展示六爻装卦的基础上，提供了一系列高级交互功能：

### 7.1 爻位点击分析

点击任意爻位，即时展示该爻的完整关系网——六亲关系链、四柱力量对比、十二长生宫位、与各地支的刑冲合害关系。所有关系以颜色编码：冲=红色，合=紫色，害=橙色。

### 7.2 换太极

换太极是六爻进阶分析的重要手法。激活后，以指定爻的五行作为新的「我」，重新计算所有爻位的六亲属性，帮助用户从不同角度审视卦象。

### 7.3 通道线

一套**可视化爻位地支连线系统**：用户手动点击多个爻位，App 用曲线将它们串起来。同五行纯色连线，跨五行渐变过渡，箭头指向最新点击的爻位。四柱区域也可作为连线目标。

### 7.4 纳音显示

六十甲子纳音是干支组合的声韵归类。App 内置完整的三十组纳音数据，一键开关即可在每行干支下方显示纳音小字，并以五行色彩着色。

### 7.5 二老时迁（京房时迁）

按照京房易学体系，乾卦和坤卦在夏半年与冬半年的纳甲规则有所不同。打开开关后，App 自动根据当前时间判断并执行天干互换，完全还原古法。

### 7.6 伏神模式切换

支持双伏（同时显示伏神与大伏）和单伏（仅显示伏神）两种模式，满足不同学派的分析习惯。

## 八、卦爻辞与焦氏易林 —— 经文智慧数字化

### 8.1 六十四卦全辞库

App 内置完整的《周易》经文体系，涵盖卦辞、彖辞、爻辞。

### 8.2 焦氏易林 —— 4,096 条完整覆盖

《焦氏易林》是汉代焦延寿所著的易学巨著，以六十四卦为本卦、六十四卦为变卦，共产生 **4,096 种本变卦组合**，每种配有四字韵文林辞。大爷六爻完整收录了全部 4,096 条林辞，且其中 4,081 条配有现代白话译文。

### 8.3 本地化解卦引擎

基于《增删卜易》体系的纯本地解卦引擎，6 步递进分析：卦象总论 → 世应分析 → 动爻解读 → 六亲六神概览 → 旬空提示 → 综合断语。

## 九、万年历 —— 干支历法智慧

### 9.1 完整干支日历

月历视图展示当月全部日期，每日格同时显示公历日期与干支纪日。农历日期标识月初月份名，支持闰月显示。二十四节气日优先显示节气名。

### 9.2 三维择日体系

日期详情页综合三种传统择日方法给出宜忌建议：

| 方法 | 说明 |
|------|------|
| **建除十二神** | 建、除、满、平、定、执、破、危、成、收、开、闭，按月支推算每日轮值 |
| **二十八宿** | 角亢氐房心尾箕斗牛女虚危室壁奎娄胃昴毕觜参井鬼柳星张翼轸，每日一宿及其宜忌 |
| **彭祖百忌** | 日干一条 + 日支一条，简明精炼的禁忌提示 |

## 十、AI 智能解读 —— 古典智慧 × 大模型

大爷六爻集成了 **DeepSeek 大语言模型**，提供基于《增删卜易》体系的结构化 AI 解卦服务：

- **结构化输入**：将排盘结果自动转为模型可理解的结构化文本
- **流式实时输出**：基于 SSE 协议，逐字流式返回解读内容
- **专业提示词**：内置基于《增删卜易》体系的 System Prompt
- **多模型支持**：默认使用 DeepSeek V4，支持用户自行配置 API Key
